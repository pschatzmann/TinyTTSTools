Detailed Description

Multiplicative volume/speed/voicing/pitch-contour effect derived from a single modifier value, per the mappings documented on PhonemeSynthesisParams::setPhonemeModifier() and, for the TONE_* values, on PhonemeModifier's own tone section. Extracted here (rather than left inline on that one method) so a vocoder that detects a modifier tag on an individual token – not just a caller-supplied whole-call PhonemeSynthesisParams – can apply the exact same effect without duplicating the magic numbers. voicingIsAbsolute distinguishes MOD_DEVOICED/MOD_VOICED (hard overrides to 0.0/1.0) from MOD_BREATHY (a partial multiplier onto whatever voicing already is). f0StartRatio/MidRatio/EndRatio mirror PhonemeSynthesisParams::f0StartRatio/MidRatio/EndRatio exactly – a TONE_* modifier is a shorthand for setting those three directly.
