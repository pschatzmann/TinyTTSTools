Builds one dictionary table row: PH_WORD("able", Phone::EY, Phone::B, Phone::AH, Phone::L). Each argument after the word must be a Phone enum value (see Phonemes.h) – an unrecognized ARPABET name is simply a compiler error (no name of that kind exists), so there's no separate "unknown token" check to run at dictionary-build time.

◆ cxPackPhone()

constexpr uint8_t tts_compact_dict_detail::cxPackPhone ( Phone  p)
constexpr

Packs one Phone value into a single dictionary byte: (base_id << 2) | stress. Plain Phone members (0-42) already are phoneme_map/ getPhonemeById() ids and always mean stress 0; the stressed-variant members (43+, e.g. Phone::AH1) decode via kStressedVowelBaseIds.

constexpr

phoneme_map/getPhonemeById() ids (see Phonemes.h) for the 15 vowels that have Phone::X1/Phone::X2 stressed-variant enum members, in the same order those variants are declared (Phone::AA1 first, Phone::UW2 last) – index i corresponds to enum values (43 + 2*i) and (43 + 2*i + 1).
