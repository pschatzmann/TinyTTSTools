std::vector< std::string > TinyTTSTools::toPhonemes ( const std::string &  text)
inline

Convert text to phoneme sequence.

Parameters
textInput text string to convert
Returns
Vector of phoneme symbols

Performs text preprocessing and grapheme-to-phoneme conversion:

  1. Text normalization (lowercase, punctuation handling)
  2. Word tokenization
  3. Grapheme-to-phoneme conversion using selected model
  4. Silence insertion for punctuation and word boundaries
