Say/synthesize audio for a phoneme given as a Phone enum value.

Parameters
phonePhoneme, e.g. Phone::AA or a stressed variant like Phone::IH1
outOutput stream for audio data
paramsOptional volume/duration/pitch overrides
Returns
true if synthesis successful, false otherwise

Phone always represents ARPAbet symbols (see its declaration in Phonemes.h), so this converts via Phonemes::toArpabetString() and delegates to sayPhoneme(PhonemeType::ARPAbet, ...) – translation to the vocoder's own defaultPhonemeType (if different) still applies.
