Detailed Description

Audio dictionary for encoded audio data with on-demand decoding.

This class provides an AudioDictionary implementation that can handle encoded audio data (MP3, AAC, etc.) and decode it on-demand using the provided AudioDecoder. The phoneme data is typically provided as an array of SoundEntry objects stored in PROGMEM to conserve RAM.
