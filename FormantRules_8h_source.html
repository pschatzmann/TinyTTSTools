79 // ==================== International / IPA extension (Phone ids 43-120) ====================
80 //
81 // Formant frequencies (F1-F3, male voice) are literature-informed
82 // starting points, not measured/calibrated data:
83 // - German vowels: Sendlmeier & Seebold-style average male formant charts.
84 // - French vowels/nasals: Delattre/Fant-style average male formant charts.
85 // - Everything else: approximated from the closest ARPAbet
86 // consonant/vowel by place of articulation (each entry says which,
87 // "cf. X") and adjusted per known acoustic tendencies (retroflexion
88 // lowers F3, backing lowers F2, rounding lowers F2, pharyngealization
89 // raises F1, etc.) -- dedicated formant tables for most of these
90 // segments are sparse or don't exist at all in the literature.
91 // Per the project's own listening-test standard, treat every value here
92 // as a first draft to be verified against real rendered audio and
93 // retuned by ear -- do not assume correctness from the numbers alone.
94 //
95 // Clicks, implosives and ejectives (the CL-, IM- and EJ-prefixed entries
96 // below) are a different case from everything else here: they change
97 // the *source* mechanism (a separate velaric airstream for clicks, a
98 // glottalic one for ejectives/implosives), not just the filter, so no
99 // amount of 3-formant tuning makes them accurate the way it does for an
100 // unusual place-of-articulation consonant or vowel. Those entries are
101 // best-effort approximations (short broadband bursts for clicks, stops
102 // with adjusted burst amplitude/voicing for ejectives/implosives) good
103 // enough to be distinguishable from silence and from each other, not
104 // intended as faithful synthesis -- a real source model (or a
105 // recording, per PhonemeModifiers.h's @note on when recordings are
106 // actually needed) would be required for that.
