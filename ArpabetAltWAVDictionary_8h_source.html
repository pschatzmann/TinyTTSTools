10// Auto-generated single-phoneme dictionary reusing each phoneme's own
11// {PHONEME}_SIL diphone (phoneme trailing into silence) as a standalone
12// phoneme sound. Source data is real IMA-ADPCM (bits=4), not PCM8.
13// Generated by generate_arpabet_alt_dictionary.py
14//
15// WARNING: each entry's real audio content is only ~half of the
16// phoneme's natural duration (see Phonemes.h's phoneme_map) plus a
17// ~50ms silence handoff -- that's how generate_relevant_diphones.sh
18// builds a {P}_SIL diphone for concatenation, not a full standalone
19// phoneme. PhonemeVocoder requests each phoneme's FULL table
20// duration, so playing this dictionary back plays every phoneme (most
21// audibly, vowels) for only about half its intended length before it
22// trails into silence. Use ArpabetWAVDictionary (from
23// setup/audio/phonemes-from-espeak/) for real standalone phonemes;
24// this dictionary exists only to regression-test the ADPCM decoder
25// against known-good diphone data (see tests/test_audio_format_decoder.cpp).
