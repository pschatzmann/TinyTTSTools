Detailed Description

Small helpers to remove boilerplate duplicated across example sketches (Serial startup, I2S output setup from a TTSConfig).

Optional and not pulled in by TinyTTSTools.h – include it only from a sketch that already includes AudioTools.h, so the core library headers stay free of any AudioTools-specific dependency.
