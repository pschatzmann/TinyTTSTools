Detailed Description

Voice configuration parameters for tuning timbre & prosody.

This structure contains all parameters needed to configure the FormantVocoder for different voice characteristics. Parameters are grouped by functionality:

  • Basic voice characteristics (pitch, naturalness)
  • Processing settings (overlap, gains)
  • Dynamic range control (RMS, peak limiting)
  • Naturalness features (randomization, stress)
  • Spectral shaping (nasal, sibilant processing)
