Detailed Description

One longest-match rule.

If pattern occurs at position i (optionally anchored to the end of the word via wordEndOnly), emit phonemes and advance i past it. wordEndOnly defaults false, so a language with no word-end rule category (its rule tables never set it) can omit the field entirely in an aggregate initializer, e.g. {"ll", "Y"}.
